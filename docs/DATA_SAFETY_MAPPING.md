## Data Safety Form Quick Reference

For the Play Console Data Safety form, answer:

1. **Does your app collect or share any of the required user data types?** → **Yes**
2. **Is all of the user data collected by your app encrypted in transit?** → **Yes**
3. **Do you provide a way for users to request that their data is deleted?** → **Yes** (via account deactivation — verify true deletion with backend)
4. **Data types collected:**
   - Personal info: Name, Email address, Phone number
   - Photos: Profile photo (optional)
   - App activity: Comments, Purchase history, Search history
   - App info and performance: Crash logs (via OneSignal), Diagnostics
   - Device or other IDs: Firebase Instance ID, OneSignal device ID
5. **Data types shared:** Same as collected (transmitted to backend API and third-party services)

**OWNER ACTION REQUIRED:** Verify with backend whether account deactivation truly deletes user data or merely marks the account as inactive.
